FLASK CHEAT CODE
================

1. Create a Flask application

from flask import Flask

app = Flask(__name__)


2. Create a route

@app.route("/")
def home():
    return "Hello Flask!"


3. Run the application

if __name__ == "__main__":
    app.run(debug=True)


4. Render an HTML template

from flask import render_template

@app.route("/")
def home():
    return render_template("index.html")


5. Get information from a URL

@app.route("/user/<name>")
def user(name):
    return f"Hello {name}"


6. Redirect to another route

from flask import redirect, url_for

return redirect(url_for("home"))


7. Get data from a POST request

from flask import request

name = request.form.get("name")


8. Return JSON

@app.route("/api")
def api():
    return {
        "message": "Hello API"
    }


9. Flask project structure
